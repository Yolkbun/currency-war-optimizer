# 货币战争 S2 · 阵容优化器

《崩坏：星穹铁道》货币战争 S2「入画奇航」的羁绊链路阵容优化工具。

## 用法

打开 [index.html](index.html)（或直接访问 GitHub Pages 地址）即可使用，无需安装任何东西。

1. 对着游戏里的「羁绊链路」界面，勾选已经拿到的档位
2. 选择这一局的条件（阿哈是否上场、是否有命定主角）
3. 点「开始求解」，得到 13 人阵容（前台 4 / 后台 9）、每人该戴的星徽、本局能新增的档位与星琼

## 说明

- 单文件实现：数据 + 求解器全部内嵌，纯前端运行，不联网、不上传任何数据
- 求解方式：分支定界 + 背包上界 + 局部搜索；状态栏会标明是「已证明最优」还是「限时内最优解」
- 规则口径：13 人 / 每人 ≤3 星徽 / 星徽只补角色没有的羁绊 / 阿哈上场欢愉·幻月 +13 / 命定主角 +2 / 饮月天赋（前台生效，自动判断）
- 前提：默认按「已有三星五费翡翠」计算，不校验费用
