# 货币战争 S2 · 阵容优化器

《崩坏：星穹铁道》货币战争 S2「入画奇航」的羁绊链路阵容优化工具。

## 在线使用

**https://yolkbun.me/currency-war-optimizer/**

（备用地址：https://yolkbun.github.io/currency-war-optimizer/）

打开即用，纯前端运行，不联网计算、不上传任何数据。

## 用法

1. 对着游戏里的「羁绊链路」界面，勾选已经拿到的档位
2. 选择这一局的条件（阿哈是否上场、是否有命定主角；模式 2 可指定必须完成的羁绊）
3. 点「开始求解」，得到 13 人阵容（前台 4 / 后台 9）、每人该戴的星徽、本局能新增的档位与星琼

## 说明

- 单文件实现：`index.html` 内嵌全部数据与求解器，只有一个文件，可离线保存使用
- 求解方式：分支定界 + 背包上界 + 局部搜索；结果会标明「已证明最优」还是「限时内最优解」
- 规则口径：13 人 / 每人 ≤3 星徽 / 星徽只补角色没有的羁绊 / 阿哈上场时欢愉·幻月 +13 / 命定主角 +2 / 饮月天赋（上场且在前台生效，自动判断并在结果里注明）
- 前提：默认按「已有三星五费翡翠」计算，不校验费用

## 数据

61 名角色 / 23 个羁绊 / 67 个档位；其中云上五骁、少女乐队、守护三个羁绊没有星徽，只能靠真人上阵。
